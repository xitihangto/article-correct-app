# 高三英语作文批改

> 一个 macOS 本地 App：把学生作文批成一份可直接下发的 Word 批改稿，点一下就好。
>
> 不用碰命令行，不用另外装东西，打开就能用。

---

## 它是干什么的

老师手里有两份文件：**一份作文题目、一份学生作文**，想把它们变成一份带红笔批注、纠错清单和升格终稿的批改稿。

这个 App 就是把这件事做完：

1. 你选好作文题目和学生作文，点「生成作文批改」
2. App 在内置浏览器里登录 DeepSeek，按既定的《作文批改规则》，让 AI 写出生成批改稿的 Python 脚本
3. App 用自带的 Python 运行这段脚本，产出排版好的批改稿 docx
4. 生成完成后，在 Word 卡里点「下载 Word 批改稿」，存到你想放的地方

目标用户是一位高三英语老师，平时批量批改学生作文用。

---

## 基本功能

| 功能 | 说明 |
| --- | --- |
| 上传题目和作文 | 选两个 docx：作文题目 + 学生作文，一起交给 AI |
| 按规则批改 | 内置批改规则和标准批改版式，输出四段：作文要求 / 学生作文 / 修改意见 / 终稿 |
| 红笔标注 | 原文黑色、需改处红色、终稿溯源编号蓝色，和人工批改的视觉一致 |
| 内置 DeepSeek 浏览器 | 不用开 Safari，不用给 Apple 事件授权；登录一次后会话保存在 App 自己的容器里 |
| 浏览器全程隐形 | 生成时浏览器不露面，只有登录时才显示一次，登录成功 5 秒后自动收起 |
| 自动等、自动续 | 每 5 秒播报一次进度和代码字数；AI 写到一半停了，会自动点「继续生成」续上；整轮等待上限 10 分钟 |
| 模式检测 | 登录后自动检测「深度思考、联网搜索」是否已激活，绿灯亮了才开始检测 |
| 下载 Word 批改稿 | 生成完成后在 Word 卡下载 docx，下载成功后临时文件自动清理 |
| 退出 DeepSeek | 页脚菜单里可以退出 DeepSeek 账号，退出时清掉 cookie 和本地存储 |
| 失败自动留诊断 | 生成失败时自动写诊断日志和页面截图，保存在 `~/Library/Application Support/作文批改/日志/`，最近 30 份 |

## 批改稿长什么样

```text
高三英语写作训练《题名》批改与升格

一、作文要求        原题 Directions 与中文要求，原文照录
二、学生作文        手写稿完整转录，保留学生原有错误，末尾注明词数
三、修改意见        （一）纠错 纠1…纠N：重录原文，需改处红字，→ 修改为：…
                    （二）补充意见 意1…意M：位置 + 可直接插入的英文原句
四、终稿            唯一版本，每句后蓝色〔纠3〕〔意1〕标注落实了哪条意见
```

版式照《标准模式批改》：A4，上下 2 cm、左右 2.2 cm，中文宋体、英文 Times New Roman，
行距 1.15，段间不空行，正文首行缩进。

## 界面

- 主背景是实色，不花哨，字看得清
- 上传卡、进度卡、Word 卡和按钮用液态玻璃质感（macOS 26 及以上，低版本自动回退到普通样式）
- 退出确认框：退出在左、取消在右，回车是退出，Esc 是取消；Cmd+Q 不受影响
- 登录状态行是单行固定高度，登录前后窗口不会忽高忽低
- 按钮先保证能点，再谈好不好看：任何 hover 效果都不会挡住点击

## 从源码构建

```bash
cd article-correct-app
./build.sh              # 只构建到 dist/高三英语作文批改.app
./build.sh --install    # 构建 + 覆盖安装到 /Applications + 启动
```

没有 Xcode 工程，纯 `swiftc` 手工组装。产物约 77MB，其中约 75MB 是自带的 Python 3.12 + python-docx 运行时，所以用户机器上不用再装 Python。

两个自检入口：

```bash
"dist/高三英语作文批改.app/Contents/MacOS/EssayCorrect" --selftest
"dist/高三英语作文批改.app/Contents/MacOS/EssayCorrect" --runpython tools/sample_build.py
```

## 需要注意的几点

- **只支持 macOS**，用的是苹果的 SF Symbol、液态玻璃这些系统专属的东西，换平台要重写。
- **要登录 DeepSeek 网页版**，批改稿是经由你登录的 DeepSeek 账号生成的；退出账号后会话会被清掉。
- **上传目前只收 doc / docx**，图片、PDF、粘贴暂时不支持（以后改版会加）。
- **AI 写完的判定偶尔会误判**，这是这类自动化的通病；失败时先看自动留下的诊断日志和截图，再重跑一整轮。
- **不要用 JS 点击去点「继续生成」**，DeepSeek 会检查事件是不是真实的，App 里用的是真实鼠标事件注入，这一点别改回 JS 点击。
